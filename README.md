# 比例ラボ 第2週

中学1年 数学「4章 比例と反比例」の第2週(座標・比例のグラフ)用の練習ゲームです。
方眼を直接タップして点を置きながら進めます。

## ステージ

| ステージ | 内容 |
|---|---|
| 座標をよめ | コインの位置を (x, y) で答える |
| 点をうて | 言われた座標の交点をタップしてコインを置く |
| グラフをかけ | y = ax のグラフを「原点+もう1点」でかき、増加・減少も答える |
| 式をよめ | グラフが通る点を見つけて、y = ax の a を求める |
| ボス戦 | 全部まぜて10問、ハート3つ |

`index.html`・`icon.png`・`.nojekyll` の3つを同じフォルダに置いてください(`icon.png` はスマホのホーム画面用アイコン)。

## 公開のしかた

第1週と同じです。`hirei-lab-w1` と同じリポジトリに、この `hirei-lab-w2` フォルダごとアップロードすると、
`https://ユーザー名.github.io/リポジトリ名/hirei-lab-w2/` で開けます。

進捗記録を使う場合は、`index.html` の `LOG_URL` と `LOG_KEY` に第1週と同じURL・合言葉を入れてください。
同じスプレッドシートに「比例ラボ 第2週」として記録されます。

記録(星・コイン・ミスの回数)は第1週とは別に保存されます。
